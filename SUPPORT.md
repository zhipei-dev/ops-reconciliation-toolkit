# Support

This repository is a public portfolio project and does not include a paid support contract or SLA.

## Questions and defects

Use GitHub Issues for:

- reproducible parsing or reconciliation defects
- API/dashboard problems
- setup or handoff documentation gaps
- narrowly scoped enhancement requests

Include the .NET SDK version, operating system, command, synthetic fixture details, expected outcome, and observed outcome where relevant.

## Security and data

Do not post credentials, private financial data, customer exports, or other sensitive information in public issues. Reproduction cases should use synthetic data only.

Review `docs/SECURITY_AND_LIMITATIONS.md` before reporting behavior that may be an intentional portfolio boundary.

## Scope

Support covers the documented synthetic reconciliation workflow. Production accounting integration, identity, retention, compliance, FX processing, hosting, and operational SLAs are outside scope.
